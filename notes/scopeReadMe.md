# مشكلة النطاق (Scope Bug): الفرق بين var و let داخل الحلقة

## المثال الأول: استخدام var

عند استخدام `var` داخل الحلقة، فإن جميع الدوال تشترك بالمتغير نفسه؛ لأن `var` لها نطاق على مستوى الدالة (Function Scope).

بعد انتهاء الحلقة، تصبح قيمة المتغير `i` هي 3، ولذلك عندما نستدعي الدوال الثلاث، فإن جميعها تُرجع القيمة 3.

**الناتج:**

```js
[3, 3, 3];
```

## المثال الثاني: استخدام let

عند استخدام `let` داخل الحلقة، يحصل كل تكرار (Iteration) على ارتباط مستقل بالمتغير؛ لأن `let` لها نطاق على مستوى الكتلة (Block Scope).

كل دالة تحتفظ بالقيمة الخاصة بالمتغير `i` من التكرار الذي أُنشئت فيه.

**الناتج:**

```js
[0, 1, 2];
```

## الخلاصة (Conclusion)

- ال `var`: لها نطاق على مستوى الدالة (Function Scope)، لذلك تشترك جميع الدوال بالمتغير نفسه.
- ال `let`: لها نطاق على مستوى الكتلة (Block Scope)، لذلك يحصل كل تكرار على ارتباط مستقل بالمتغير.
- استخدام `let` يساعد على تجنب مشكلة النطاق الشائعة عند إنشاء دوال داخل الحلقات.
